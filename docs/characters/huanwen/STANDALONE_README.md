# 染紫鎏痕·桓温 4.2

适用于《无名杀》的独立武将扩展。运行前须先安装《无名杀》：<https://github.com/libnoname/noname>。

## 安装

1. 解压 `huanwen-extension-v4.2.0.zip`。
2. 将“染紫鎏痕·桓温”文件夹复制到《无名杀》的 `extension` 目录。
3. 确认路径为 `extension/染紫鎏痕·桓温/extension.js`。
4. 重启游戏，在“选项 → 扩展”中启用“染紫鎏痕·桓温”。

## 武将技能

**染紫鎏痕·桓温　晋　3/3**

**【遂宁】** 每轮开始时，若场上没有“成”，你可以令距离1以内的一名其他角色获得“成”标记。当你使用或打出【闪】时，你可以进行判定，若结果为：红色，你获得所响应牌的使用者的一张牌；黑色，你对其造成1点伤害。  
当你对有“成”的角色累计造成3点伤害后，或其进入濒死状态时，你加1点体力上限并将体力回复至体力上限，将〖三伐〗改为“出牌阶段限三次”，然后移去“成”标记并失去此技能。

**【伏火】** 你可以将一张锦囊牌当【闪】使用或打出；出牌阶段限一次，你可以将一张锦囊牌和一张基本牌当【火攻】使用。

**【三伐】** 出牌阶段限一次，你可以用一张手牌交换牌堆顶的一张牌，然后亮出牌堆顶的三张牌，将其中至多两张置于牌堆顶，其余的牌各置入牌堆底或弃置，然后从牌堆底摸X张牌（X为亮出的牌中同花色牌数的最大值）。若X不小于2，你于此阶段能使用【杀】的次数+1；若X为3，你于此阶段使用的下一张牌不可被响应，且你加1点体力上限。

**【慎图】** 锁定技，出牌阶段结束时，若你于此阶段造成的伤害值小于你发动〖三伐〗的次数，你减1点体力上限。

## 源码结构

- `extension.js`：扩展入口与武将注册。
- `character.js`：武将数据。
- `skill.js`：技能实现。
- `rules.js`：规则计算与事件辅助函数。
- `sanfa-interface.js`：〖三伐〗分配界面。
- `translate.js`、`dynamicTranslate.js`：游戏内文本。
