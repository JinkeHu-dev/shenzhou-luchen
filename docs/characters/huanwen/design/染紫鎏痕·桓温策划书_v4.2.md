## 技能描述

【遂宁】每轮开始时，若场上没有“成”，你可以令距离1以内的一名其他角色获得“成”标记。当你使用或打出【闪】时，你可以进行判定，若结果为：红色，你获得所响应牌的使用者的一张牌；黑色，你对其造成1点伤害。

当你对有“成”的角色累计造成3点伤害后，或其进入濒死状态时，你加1点体力上限并将体力回复至体力上限，将〖三伐〗改为“出牌阶段限三次”，然后移去“成”标记并失去此技能。

注：黑色判定的伤害对象是所响应牌的使用者，不限于“成”；只有对“成”造成的伤害计入累计。场上同时只能有一个“成”。“每轮开始时”即可指定，后手的桓温在自己第一个回合之前就能推进。

【伏火】你可以将一张锦囊牌当【闪】使用或打出；出牌阶段限一次，你可以将一张锦囊牌和一张基本牌当【火攻】使用。

注：以此法使用或打出的【闪】同样可以触发〖遂宁〗的判定。【火攻】不能用【闪】响应。

【三伐】出牌阶段限一次，你可以用一张手牌交换牌堆顶的一张牌，然后亮出牌堆顶的三张牌，将其中至多两张置于牌堆顶，其余的牌各置入牌堆底或弃置，然后从牌堆底摸X张牌（X为亮出的牌中同花色牌数的最大值）。若X不小于2，你于此阶段能使用【杀】的次数+1；若X为3，你于此阶段使用的下一张牌不可被响应，且你加1点体力上限。

注：放回牌堆顶和置入牌堆底的牌，顺序由你决定。摸牌从牌堆底最下面一张开始；置入牌堆底的牌多于X张时，多出的留在牌堆底，下次发动时可以摸回。牌堆顶至多留两张，三张同花色不能整组留到下一次。“下一张牌不可被响应”包括锦囊牌。

【慎图】锁定技，出牌阶段结束时，若你于此阶段造成的伤害值小于你发动〖三伐〗的次数，你减1点体力上限。

注：未发动〖三伐〗的阶段不触发。伤害按实际造成的数值计算；回合外〖遂宁〗造成的伤害不在出牌阶段内，不计入。

各技能的触发时机、发动者、作用对象、次数与代价，汇总于第七部分“规则要素一览”。

## 一、设计定位

### （一）体验目标

桓温的玩法分为两个阶段。第一阶段，玩家锁定一名近处的对手，借〖遂宁〗逐步完成征服；第二阶段，〖三伐〗由每阶段一次扩展为三次，进入以亮牌决定收益的进攻回合。前一阶段对应平定成汉，后一阶段对应三次北伐。

### （二）职能与强度定位

从对局职能看，桓温具有以下五项特征：

- 二阶段成长：完成〖遂宁〗前后，〖三伐〗由每阶段一次变为三次，单回合强度明显提高。

- 回合外防御：〖伏火〗可将锦囊牌当【闪】；〖遂宁〗还能在响应后获得牌或造成伤害。

- 回合内过牌：〖三伐〗在调整手牌结构的同时补充手牌，为连续出牌提供资源。

- 强制命中：〖遂宁〗的直接伤害、〖伏火〗转化的【火攻】和三同花后的不可响应，共同压缩目标角色【闪】的价值。

- 生存短板：初始体力为3，防御依赖手中的锦囊牌；锦囊不足时，防线会明显变薄。

强度目标对标新服强势武将，如武陆逊、武诸葛亮。作者先手实测中，桓温的过牌量与防御低于武陆逊，优势集中在完成〖遂宁〗后的连续发动与不可响应收益；这一结论仍需多人局数据验证。

### （三）参照对象

规则层面参照了三名官方武将。赵俨以“手牌花色相同”为条件给予额外的【杀】；薛灵芸观看牌堆顶并取走其中一部分，一回合内次数有限；徐氏〖问卦〗将牌置于牌堆一端、从另一端摸牌。〖三伐〗“牌堆顶布置、牌堆底取牌”的写法即受徐氏启发；反过来，徐氏这类会从牌堆底摸牌的角色，也能截走桓温存下的牌。

理论层面，关于随机性在游戏中的位置及其与玩家决策的关系，参考了Costikyan对不确定性来源的讨论；关于以惩罚抑制优势扩大的思路，参考了游戏设计研究中对正负反馈的论述。

### （二）关于笮桥之战的处理

《晋书》记笮桥之胜，归因于“鼓吏误鸣进鼓”，将战局的转折写作偶然。〖遂宁〗的判定写作“你可以进行判定”，是否借【闪】转守为攻，由玩家决定。规则由此为史传的叙述提供了另一种可能：转折未必出于误鸣，也可以是主帅有意为之。现行版本的黑色判定直接伤害来犯者，与笮桥之战“于是攻之，势众大溃”的方向一致：反击的对象正是来攻之敌，而不是另一处的“成”。

### （三）关于粮运与牌堆底

桓温三次北伐，两次因粮运不继而还：伐前秦时指望就地取麦为军资，苻健先行芟苗清野；伐前燕时袁真打不开石门，军粮竭尽，焚舟步退。现行〖三伐〗把牌堆底作为后方：亮出的好牌可以存进去，但每次只能按X张取回，X由本次亮牌的战果决定。交换只动牌堆顶，不能从牌堆底直接取牌，后方补给因而不能随取随用。若改为交换牌堆底，桓温每次都能直接调出一张存好的牌，等于把史传中的短板写成了强项，这是选择交换牌堆顶的主要史实理由（取舍见第三部分（四））。

## 三、核心机制与规则设计

### （一）〖三伐〗的概率与排序

- 三档离散结果。亮出的三张牌只有“全不同花”“两张同花”“三张同花”三种结果，概率依次为37.5%、56.25%、6.25%。结果空间小，便于即时判读；分布明显偏斜。玩家先决定是否发动，再承担亮牌风险。

- 前后两次亮牌相互关联。留在牌堆顶的牌会进入下一次亮牌。留下两张同花，下一次必出对子，三同花概率由6.25%升至25%；留下两张不同花，下一次出对子的概率为50%。

- 以手牌交换牌堆顶。发动时不损失牌差，却会改变下一次亮牌的结构；若要保住留下的对子，须用一张同花色手牌交换。

- 从牌堆底摸X张。得牌数只由本次亮牌的同花色数决定，与怎样安排亮出的牌无关。

牌堆顶最多保留两张已知牌，交换后的第三张仍然未知；亮出的好牌可以存入牌堆底，本次未摸完的牌继续保留。玩家能够预见行动的大致后果，结果又不会完全确定。

### （二）〖三伐〗的规则设计

- 牌堆承担状态。已知的顶牌与存入的底牌直接保存玩家的计划，无须额外标记或建立独立牌区。

- 一个X管三件事。X决定奖励档位、本次摸牌数和存牌取回速度，规则中不再引入第二个数字。

- 限制写在数量上。“至多两张置于牌堆顶”让对子可以整对留下，却不能留下三同花，无须追加条件句。

- 控顶的代价自然产生。保住留下的对子，需要一张同花色手牌交换；手牌越少越难做到，无须另设代价。

- 强化与近失。三档结果形成可变比率强化；两张同花已经获得收益又接近最高档，促使玩家继续追求三同花。

- 规则与史实同构。牌堆顶是前线，牌堆底是辎重，补给按战果运来；出兵必求有获，否则付出代价。

### （三）技能间的衔接

- 〖遂宁〗与〖三伐〗：指定“成”建立前期目标；累计造成3点伤害或令其进入濒死后，〖三伐〗由每阶段一次改为三次，完成两阶段转换。

- 〖伏火〗与〖遂宁〗：〖伏火〗转化的【闪】同样触发〖遂宁〗，使锦囊牌同时承担防御与推进征服的作用。

- 〖三伐〗与〖慎图〗：每次发动都要以阶段内伤害兑现；发动越多，牌与奖励越多，需要承担的伤害门槛也越高。

- 三处强制命中分布在不同时间：回合外的〖遂宁〗直接伤害、每阶段一次的〖伏火〗【火攻】和三同花后的下一张不可响应牌互不重叠。

## 四、实战决策与对抗

### （一）实战决策

- “成”的人选。对象须在距离1以内，手牌宜少、体力宜低。首轮可暂不指定，待局势明朗后再定。

- 锦囊的用途。当【闪】以保命并触发〖遂宁〗；加一张基本牌当【火攻】以推进征服；或按原效果使用。

- 先打后伐。先用现有的牌进攻，有了战果再发动〖三伐〗，可以把〖慎图〗的风险降到最低。对子的奖励作用于整个阶段，先出过的【杀】不会让它浪费。本文模型中，量力发动（稳健）与每回合必发动（积极）相比，〖慎图〗触发从每局2.2次降到0.2次，八轮存活率从71%升到96%，代价是〖遂宁〗完成后每回合伤害从1.39点降到1.00点（乐观假设）。

- 留哪两张、用哪张手牌交换。留下了对子，就用一张同花色的手牌去换顶牌，保住对子；留下了两张不同花，就用与第二张同花色的手牌换掉第一张，凑成对子。手里没有合适花色时，对子会被拆开。

- 最后一次发动不留牌。留在牌堆顶的牌会被下家摸走。最后一次发动时，好牌存入牌堆底，留到下回合再取；没用的牌弃置。

- 发动次数（完成〖遂宁〗后）。每多发动一次，平均多约1.7张牌和一次增加【杀】次数的机会，但〖慎图〗要求的伤害也多1点。

- 三同花之后的“下一张牌”。用在【决斗】或【南蛮入侵】上最值。不要先使用【酒】或装备，以免白白耗掉。

### （二）对抗分析

- 用不经【闪】的伤害：【决斗】【南蛮入侵】【火攻】【闪电】与失去体力不会触发〖遂宁〗，既不会被反伤，也不推进“成”的进度。本文模型中，若“成”是主要进攻者且只用这类伤害，完成平均推迟0.3—0.4轮，两轮内完成率降15—18个百分点（每轮1.0张时）。

- 派卖血角色施压：受到伤害反而获益的角色（如郭嘉〖遗计〗、荀彧〖节命〗）不怕反伤，适合在桓温完成〖遂宁〗之前施压。

- 把握集火时机：〖遂宁〗完成前，桓温体力为3，是集火的窗口。本文模型中，指向桓温的【杀】由每轮0.6张增至1.2张，八轮存活率从71%降到48%（乐观假设）。但用【杀】集火会触发〖遂宁〗，进攻者要承担反伤或被拿走一张牌。

- 削减防御资源：以【过河拆桥】【顺手牵羊】移除其手中的锦囊与【闪】，削弱〖伏火〗。

- 限制行动阶段：以【乐不思蜀】使其跳过出牌阶段。

- 拉开距离：〖遂宁〗完成后“成”标记移除，桓温缺少无距离限制的手段，攻击范围仅为1。

- 干预判定：具有改判能力的角色可修改〖遂宁〗的判定。

- 截取存牌：会从牌堆底摸牌的角色（如徐氏〖问卦〗）可以拿走桓温存在牌堆底的牌。

玩家熟悉桓温之后，军八中会倾向于先除掉他，阻止他进入每阶段三次〖三伐〗的阶段。难点在于找到执行者：用【杀】进攻要承担反伤，合适的执行者只有握有不经【闪】伤害手段的角色或卖血角色。克制手段少，本身就是桓温强度的一部分；如需削弱，见第六部分。

### （三）先手与后手

作者此前只实测了先手局。问题：军八中后手的桓温，到自己的回合时可能已经为防御用掉了【闪】和锦囊，手牌不多。此时连续发动〖三伐〗的表现会不会变差？推演结果分三点。

- 首回合的手牌差得不多。出牌阶段开始时，先手平均6.0张；后手在常规压力下为5.7张，集火时为5.5张。

- 〖三伐〗本身的产出几乎不受手牌影响。固定发动三次时，手牌2张与6张相比，对子以上次数为2.37对2.54，三同花为0.44对0.53。牌堆顶交换保对子要有同花色手牌，所以手牌少时略降；换牌堆底的4.1不受影响，手牌只剩2张时两者持平。

- 受影响的是兑现。手牌少，能打出的伤害少，〖慎图〗的风险随之上升，玩家只能少发动几次。积极打法下，手牌2张时一阶段平均只发动1.3次，伤害1.06点，〖慎图〗触发43%；手牌6张时为2.1次、2.52点、16%（乐观假设）。

后手也有补偿。〖遂宁〗“每轮开始时”即可指定“成”，在桓温第一个回合之前，他人回合里打出的【闪】就能触发判定；上一回合存入牌堆底的牌，也能在手牌少时补上。本文模型中，后手完成〖遂宁〗的时间与先手相同，八轮存活率反而略高。结论是：手牌少时，连续三伐的“抽”不变，“打”变弱；〖遂宁〗前期提供的防御足以支撑后手度过第一轮。

### （四）与武陆逊的比较

作者实测（先手局），现行桓温强于武陆逊。武陆逊的过牌量与防御都高于桓温，桓温胜在三处强中：〖遂宁〗的反伤、〖伏火〗的【火攻】、三同花后的“下一张牌”。对手手里的【闪】对这三种伤害都无效，对手防御越厚，强中越值钱。本文模型没有计入这一点（目标的防御只用【闪】的张数与【八卦阵】概率表示），也没有计入群体锦囊对其他敌人的伤害，因此模型中的伤害数字偏保守，强度判断以实测为准。

### （六）推演假设与局限

- 只追踪桓温本人。牌堆按军争160张，牌型按张数比例抽取，花色等概率且与牌型独立。

- 每轮开始即指定一名相邻的敌方为“成”，体力为4；他人每轮有40%概率对“成”造成1点伤害。〖遂宁〗完成后，乐观假设下每回合都能攻击到目标，保守假设下为六成回合。

- 他人每轮平均对桓温使用0.6张需要【闪】响应的牌（集火时1.2张），其中三分之一来自“成”；桓温以【闪】或锦囊（〖伏火〗）响应。

- 乐观假设：目标平均持有0.6张【闪】，无防具。保守假设：目标平均持有1.25张【闪】，三成概率装备【八卦阵】。

- 积极打法：先用现有的牌进攻，再发动〖三伐〗，每回合至少发动一次；之后若已有足够战果，或手里还有进攻牌，就继续发动。稳健打法：第一次发动也须满足这一条件。

- 控顶：每阶段最后一次发动不留牌；中间的发动出对子留对子，全不同花时留两张，并尽量让第二张的花色是手里有的；价值低的牌弃置，其余存入牌堆底。

- 未计入：【无懈可击】、群体锦囊对其他敌人的伤害、击杀的奖惩、洗牌、其他角色从牌堆底摸牌、强中对防御的绕过价值。

- 数值适合比较版本与打法，绝对值以实测为准。

### （一）初稿原文

以下据设计稿照片转录，照片较模糊，个别字句待作者核对。原文照录，不作改动。

温　体力3

【平蜀】当你打出闪时，你进行一次判定：红色，下一次摸牌阶段摸牌数加一；黑色，此闪无效，并视为你对其打出x张无视防具的杀。若此回合内有角色因此进入濒死状态，你失去此技能。

【三伐】出牌阶段限3次，你可以观看牌顶堆3张牌，并根据这3张牌中相同花色的牌数获得以下效果：

0张，选择3张其中一张牌获得。然后本回合此技能可以发动的次数减一，剩下观看牌中的每张牌你可以按任意顺序放回或弃置；

2张，你从中选择1-2张牌获得。然后此阶段出牌无次数限制，剩下观看牌中的每张牌你可以按任意顺序放回或弃置；

3张，将所有观看牌放入弃牌堆后，摸3张牌。然后此阶段出牌无距离限制并增加1点体力上限。

【慎图】出牌阶段结束时，若你本回合发动三伐的次数为3且造成过伤害，你失去一点体力上限；若你未对其他角色使用过手牌，则手牌上限+1。

### （二）初稿中保留下来的设计意图

- 控顶：初稿说明即称〖三伐〗“集摸牌、控顶、增益”于一身，且技能收益依赖于控顶。现行版本把控顶与得牌分开，使控顶不再以少拿牌为代价。

- 反伤的博弈：对手对桓温使用【杀】之前，须考虑其手中是否有【闪】。现行黑色判定直接伤害来犯者，这一博弈更加明确。

- 慎图的立意：抑制优势的滚雪球。现行写法改为惩罚“出兵而无战果”。

#### 1．analytic.py　〖三伐〗亮牌概率的精确枚举

对应：第五部分（一）。状态：本次补写，结果与正文一致。

```python
# ============================================================
# analytic.py —— 〖三伐〗亮牌概率的精确枚举（不含模拟）
# 用途：第五部分（一）“三伐的概率与收益（解析计算）”表中的概率。
# 运行：python3 analytic.py      仅用标准库，无随机数，结果精确。
# 假设：每张牌的花色在四种花色中等概率且相互独立（不计牌堆内花色的实际消耗）。
# ============================================================
from itertools import product
from fractions import Fraction

def dist(known):
    """已知牌堆顶留有 known（花色列表）时，亮出三张后最大同花色数X的分布。
    known 的长度为0、1或2；其余位置的花色逐一枚举。"""
    free = 3 - len(known)
    out = {1: Fraction(0), 2: Fraction(0), 3: Fraction(0)}
    for rest in product(range(4), repeat=free):
        rev = list(known) + list(rest)
        X = max(rev.count(s) for s in range(4))
        out[X] += Fraction(1, 4 ** free)
    return out

def pct(f): return f'{float(f) * 100:.2f}%'

for name, known in [('未留牌，或只留一张', []), ('留有两张同花', [0, 0]), ('留有两张不同花', [0, 1])]:
    d = dist(known)
    print(f'{name}：全不同花 {pct(d[1])}，两张同花 {pct(d[2])}，三张同花 {pct(d[3])}')

# 想用同花色手牌交换以保住对子时，手里至少有一张该花色的概率：1-(3/4)^h
for h in (3, 4, 5, 6):
    print(f'手牌{h}张时至少有一张指定花色：{pct(1 - Fraction(3, 4) ** h)}')
```

```python
# ============================================================
# sf4.py —— 单个出牌阶段的控顶比较：旧版取满、旧版留顶、4.0
# 用途：比较“4.0控顶是否失去意义”（逐句取舍第8项“亮出的牌如何放置”）。
# 运行：python3 sf4.py           每组20万次，只考虑花色。
# 模式：old_take=旧版获得X张、其余弃置（不控顶）；
#       old_keep=旧版出对子只拿1张，把同花两张留在牌堆顶；
#       v4=4.0：同花两张留顶，摸X张；全不同花时留两张异花。
# 输出：净得牌、杀次数+1的次数、三同花次数、至少一次三同花的比例（发动1至3次）。
# ============================================================
import random
from statistics import mean
def phase(r,uses,mode):
    top=[]  # 已知留在牌堆顶的花色
    cards=0; sha=0; tri=0
    for _ in range(uses):
        rev=top[:3]+[r.randrange(4) for _ in range(3-len(top[:3]))]
        cnt={s:rev.count(s) for s in set(rev)}; s,X=max(cnt.items(),key=lambda kv:kv[1])
        if X>=2: sha+=1
        if X==3: tri+=1
        if mode=='old_take':      # 旧版：取满，其余弃置
            cards+=X; top=[]
        elif mode=='old_keep':    # 旧版：出现对子/三同花只取1张，同花两张留顶
            if X>=2: cards+=1; top=[s,s]
            else: cards+=1; top=[]
        elif mode=='v4':          # 4.0：放1张入底，同花两张留顶，摸X张
            cards+=X
            if X>=2: top=[s,s]
            else:
                o=[c for c in rev]; top=o[1:3]   # 两张不同花留顶
    return cards,sha,tri
r=random.Random(1); N=200000
for uses in (1,2,3):
    for m in ('old_take','old_keep','v4'):
        res=[phase(r,uses,m) for _ in range(N)]
        print(uses,m,'净得牌=%.2f'%mean(x[0] for x in res),'杀+=%.2f'%mean(x[1] for x in res),
              '三同花次数=%.2f'%mean(x[2] for x in res),'至少一次三同花=%.1f%%'%(100*mean(x[2]>0 for x in res)))
```

```python
 '3.0': dict(swap='bottom',acq='take',pair='unlim',triple='all',free=False,black='dmg'),
 '4.1': dict(swap='bottom',acq='b1x',pair='+1',triple='next_any',free=False,black='dmg'),
 '4.2': dict(swap='top',acq='top2',pair='+1',triple='next_any',free=False,black='dmg'),
 '4.2b': dict(swap='top',acq='top2',pair='+1',triple='next_any',free=False,black='dmg',x2keep=True),
}
def cfg(cons):
    return dict(mu=1.25 if cons else 0.6, bagua=0.3 if cons else 0.0, reach=0.6 if cons else 1.0,
                duel_mu=1.2 if cons else 0.8, armor=0.25 if cons else 0.1)

class Dead(Exception): pass

class Sim:
    def __init__(s,r,ver,cons,seat='first',lam=0.6,q=0.0,adaptive=True,black=None,R=8,policy='active',p_cheng=1/3,other_dmg=0.4):
        s.r=r; s.v=dict(VERS[ver]); s.ver=ver
        if black: s.v['black']=black
        s.c=cfg(cons); s.seat=seat; s.lam=lam; s.q=q; s.adaptive=adaptive; s.R=R; s.policy=policy; s.p_cheng=p_cheng; s.other_dmg=other_dmg
        s.hp=s.mx=3; s.hand=[nc(r) for _ in range(4)]
        s.top=[]; s.bottom=[]           # bottom[0]为最下面一张
        s.done=None; s.prog=0; s.cheng=4
        s.st=dict(pre=[],post=[],post_uses=[],post_st=[],post_tri=[],post_pair=[],reflect=0,turn_hand=[],first_hand=None,shentu=0)
    # ---------- 工具 ----------
    def lowest(s,cards,suit=None):
        cand=[c for c in cards if suit is None or c[1]==suit]
        return min(cand,key=val) if cand else None
    def complete(s,rd):
        if s.done is None:
            s.done=rd; s.mx+=1; s.hp=s.mx
    def progress(s,n,rd):
        if s.done is None:
            s.prog+=n; s.cheng-=n
            if s.prog>=3 or s.cheng<=0: s.complete(rd)
    def take_damage(s):
        s.hp-=1
        while s.hp<=0:
            t=[c for c in s.hand if c[0]=='T']
            if t: s.hand.remove(t[0]); s.hp+=1
            else: raise Dead()
    def draw_bottom(s,n):
        out=[]
        for _ in range(n):
            out.append(s.bottom.pop(0) if s.bottom else nc(s.r))
        return out
    # ---------- 三伐 ----------
    def sanfa(s,P,last):
        # 一次〖三伐〗：交换 -> 亮三张 -> 按X给奖励 -> 处理亮出的牌并摸牌。last=本阶段最后一次发动
        r=s.r; v=s.v; hand=s.hand
        # 交换
        if v['swap']=='bottom':
            H=s.lowest(hand); hand.remove(H)
            B=s.bottom.pop(0) if s.bottom else nc(r)
            hand.append(B); H[2]=False; s.bottom.insert(0,H)
        else:  # 牌堆顶交换
            want=None
            if len(s.top)==2:
                want=s.top[0][1] if s.top[0][1]==s.top[1][1] else s.top[1][1]
            H=s.lowest(hand,want) if want is not None else None
            if H is None: H=s.lowest(hand)
            hand.remove(H); H[2]=False
            if s.top: T=s.top[0]; s.top[0]=H
            else: T=nc(r); s.top=[H]
            hand.append(T)
        rev=s.top[:3]+[nc(r) for _ in range(3-min(3,len(s.top)))]   # 亮牌：先亮已知的顶牌，不足三张时补未知牌
        s.top=[]
        cnt={}
        for c in rev: cnt[c[1]]=cnt.get(c[1],0)+1
        suit,X=max(cnt.items(),key=lambda kv:kv[1])
        # 奖励
        if X>=2:
            P['pairs']+=1
            if v['pair']=='+1': P['lim']+=1
            else: P['unlim']=True
        if X==3:
            P['tri']+=1; s.mx+=1
            if v['triple']=='next_sha': P['nsha']+=1
            elif v['triple']=='all': P['all']=True
            else: P['nany']=1
        # 获得
        acq=v['acq']
        if acq=='take':
            rev.sort(key=val,reverse=True)
            for c in rev[:X]:
                c[2]=v['free']; hand.append(c)
        elif acq=='b1x':
            if not last:
                if X>=2:
                    same=sorted([c for c in rev if c[1]==suit],key=val)
                    keep=same[:2]
                else:
                    keep=sorted(rev,key=val)[:2]
                place=[c for c in rev if all(c is not k for k in keep)]
                s.top=keep
            else:
                place=sorted(rev,key=val,reverse=True)[:X]
            place.sort(key=val)  # 最好的放最下
            for c in place: s.bottom.insert(0,c)
            hand.extend(s.draw_bottom(X))
        else:  # top2（4.2）：牌堆顶至多两张，其余置底或弃置，从牌堆底摸X
            # 留牌策略：出对子留对子；全不同花时留价值最低的两张，并让第二张的花色是手里有的
            if not last:
                if X>=2:
                    same=sorted([c for c in rev if c[1]==suit],key=val)
                    keep=same[:2]
                elif v.get('x2keep'):
                    keep=[]
                else:
                    hs=set(c[1] for c in hand)
                    low=sorted(rev,key=val)[:2]
                    # 第二张的花色尽量是手里有的，下一次可凑成对子
                    if low[1][1] not in hs and low[0][1] in hs: low=[low[1],low[0]]
                    keep=low
                rest=[c for c in rev if all(c is not k for k in keep)]
                s.top=keep
            else:
                rest=rev
            place=sorted([c for c in rest if val(c)>=4],key=val)   # 有用的牌存入牌堆底（最好的在最下面，先摸到），无用的弃置
            for c in place: s.bottom.insert(0,c)
            hand.extend(s.draw_bottom(X))
    # ---------- 出牌 ----------
    def attack(s,P,rd,tgt):
        # 用现有手牌进攻：先把“下一张不可被响应”用在决斗/杀/群体锦囊上，再打决斗、群体锦囊、火攻（含伏火），最后出杀
        r=s.r; c=s.c; hand=s.hand
        def deal(n):
            P['dmg']+=n
            if tgt['cheng']: s.progress(n,rd)
        def unresp_flag():
            if P['all']: return True
            if P['nany']>0: P['nany']=0; return True
            return False
        def use_sha():
            buff=0
            js=[x for x in hand if x[0]=='J']
            if js and P['nany']==0: hand.remove(js[0]); buff=1
            sh=[x for x in hand if x[0]=='S']; hand.remove(sh[0]); P['used']+=1
            un=unresp_flag()
            if not un and P['nsha']>0: P['nsha']-=1; un=True
            if un: deal(1+buff); return
            if c['bagua'] and r.random()<c['bagua']*0.5: return
            if tgt['shan']>0: tgt['shan']-=1; return
            deal(1+buff)
        def use_duel():
            u=[x for x in hand if x[0]=='U']; hand.remove(u[0])
            if unresp_flag(): deal(1); return
            e=poisson(r,c['duel_mu']); my=sum(1 for x in hand if x[0]=='S')
            if my>=e:
                for _ in range(e): hand.remove(next(x for x in hand if x[0]=='S'))
                deal(1)
            else:
                for _ in range(my): hand.remove(next(x for x in hand if x[0]=='S'))
                s.take_damage()
        def use_aoe():
            a=[x for x in hand if x[0]=='A']; hand.remove(a[0])
            if unresp_flag() or r.random()<0.5: deal(1)
        def can_sha(): return any(x[0]=='S' for x in hand) and (P['unlim'] or P['used']<P['lim'])
        # 有“下一张牌不可被响应”时，先用在决斗/杀/AOE上
        if P['nany']>0:
            if any(x[0]=='U' for x in hand): use_duel()
            elif can_sha(): use_sha()
            elif any(x[0]=='A' for x in hand): use_aoe()
        while any(x[0]=='U' for x in hand): use_duel()
        while any(x[0]=='A' for x in hand): use_aoe()
        # 伏火火攻（每阶段一次）与真火攻
        for _ in range(3):
            fs=[x for x in hand if x[0]=='F']
            if fs:
                hand.remove(fs[0])
            elif not P['fuhuo']:
                ks=[x for x in hand if x[0]=='K']; bs=[x for x in hand if x[0] in 'SJ' and not (x[0]=='S' and can_sha())]
                if not bs: bs=[x for x in hand if x[0] in 'SJ']
                if ks and bs and len(hand)>=4:
                    hand.remove(min(ks,key=val)); hand.remove(min(bs,key=val)); P['fuhuo']=True
                else: break
            else: break
            if P['nany']>0: P['nany']=0
            m=len(hand)
            if m and r.random()<1-(0.75**m):
                hand.remove(s.lowest(hand)); deal(1)
        while can_sha(): use_sha()
    def own_turn(s,rd):
        # 自己的回合：摸两张 -> 先打后伐（按 policy 决定发动几次三伐）-> 吃桃 -> 慎图结算 -> 弃牌
        r=s.r; hand=s.hand
        hand.extend([nc(r),nc(r)])
        s.st['turn_hand'].append(len(hand))
        if s.st['first_hand'] is None: s.st['first_hand']=len(hand)
        P=dict(lim=1,used=0,unlim=False,all=False,nany=0,nsha=0,dmg=0,pairs=0,tri=0,fuhuo=False)
        pre=s.done is None
        reach = True if pre else (r.random()<s.c['reach'])
        tgt=dict(cheng=pre,shan=poisson(r,s.c['mu']))
        uses=0
        def potential():
            if any(x[0] in 'UAF' for x in hand): return True
            if any(x[0]=='S' for x in hand): return True
            if not P['fuhuo'] and any(x[0]=='K' for x in hand) and any(x[0] in 'SJ' for x in hand): return True
            return False
        if reach and s.policy in ('smart','active'): s.attack(P,rd,tgt)      # 先用现有的牌进攻
        while True:
            allowed=1 if s.done is None else 3
            if uses>=allowed or not hand or not reach: break
            if s.policy=='smart':
                safe = P['dmg']>=uses+1
                if not safe and not potential(): break
            elif s.policy=='active':
                if uses>0 and not (P['dmg']>=uses+1 or (P['dmg']==uses and potential())): break
            elif uses>0 and P['dmg']<uses: break
            s.sanfa(P, last=(uses+1>=allowed))
            uses+=1
            tgt['cheng']=(s.done is None)
            s.attack(P,rd,tgt)
        if uses==0 and reach and s.policy not in ('smart','active'): s.attack(P,rd,tgt)
        while any(x[0]=='T' for x in hand) and s.hp<s.mx:
            hand.remove(next(x for x in hand if x[0]=='T')); s.hp+=1
        if uses>0 and P['dmg']<uses:
            s.mx-=1; s.st['shentu']+=1
            if s.mx<=0: raise Dead()
            s.hp=min(s.hp,s.mx)
        if pre: s.st['pre'].append(P['dmg'])
        else:
            s.st['post'].append(P['dmg'])
            if uses>0:
                s.st['post_uses'].append(uses); s.st['post_st'].append(1 if P['dmg']<uses else 0)
                s.st['post_tri'].append(P['tri']); s.st['post_pair'].append(P['pairs'])
            else: s.st['post_uses'].append(0)
        # 弃牌
        cnt=[x for x in hand if not x[2]]
        if len(cnt)>s.hp:
            cnt.sort(key=val)
            for x in cnt[:len(cnt)-s.hp]: hand.remove(x)
        s.top=[]
    def others(s,rd):
        # 他人的回合：可能有人伤“成”；对桓温使用若干须【闪】的牌，桓温用【闪】或锦囊（伏火）响应并判定遂宁
        r=s.r; c=s.c
        s.top=[]
        if s.done is None and r.random()<s.other_dmg: s.progress(1,rd)  # 他人对“成”造成伤害（只推进濒死）
        if s.done is None and False: pass
        k=poisson(r,s.lam)
        for _ in range(k):
            if r.random()<s.q:   # 无须【闪】响应的伤害（决斗、南蛮等）
                ss=[x for x in s.hand if x[0]=='S']
                if ss and r.random()<0.5: s.hand.remove(ss[0]); continue
                if r.random()<0.6: s.take_damage()
                continue
            d=[x for x in s.hand if x[0]=='D'] or sorted([x for x in s.hand if x[0] in TRICK],key=val)
            if not d: s.take_damage(); continue
            s.hand.remove(d[0])
            if s.done is not None: continue
            if r.random()<0.5:
                s.hand.append(nc(r)); continue
            b=s.v['black']; is_cheng=r.random()<s.p_cheng
            if b=='dmg':
                s.st['reflect']+=1
                if is_cheng: s.progress(1,rd)
            elif b in ('sha','sha_unresp'):
                hit=True
                if b=='sha' and r.random()<1-math.exp(-c['mu']): hit=False
                if hit and r.random()<c['armor']: hit=False
                if hit:
                    s.st['reflect']+=1
                    if is_cheng: s.progress(1,rd)
            elif b=='sha_cheng':
                un = len(s.hand)>=4
                if un or r.random()>=1-math.exp(-c['mu']):
                    s.st['reflect']+=1; s.progress(1,rd)
    def run(s):
        alive=True
        try:
            for rd in range(1,s.R+1):
                if s.seat=='first': s.own_turn(rd); s.others(rd)
                else: s.others(rd); s.own_turn(rd)
        except Dead: alive=False
        return alive

def batch(ver,cons,N=10000,seed=7,**kw):
    # 跑N局，汇总统计。seed固定，结果可复现
    r=random.Random(seed)
    done=[];alive=0;pre=[];post=[];uses=[];stt=[];tri=[];pairs=[];refl=[];fh=[];th=[];shentu=[]
    for _ in range(N):
        g=Sim(r,ver,cons,**kw); a=g.run(); alive+=a
        done.append(g.done if g.done else 99); pre+=g.st['pre']; post+=g.st['post']
        uses+=g.st['post_uses']; stt+=g.st['post_st']; tri+=g.st['post_tri']; pairs+=g.st['post_pair']
        refl.append(g.st['reflect']); shentu.append(g.st['shentu']); fh.append(g.st['first_hand'] or 0); th+=g.st['turn_hand']
    fin=[d for d in done if d<99]
    m=lambda L: mean(L) if L else float('nan')
    return dict(完成均值=m(fin),两轮内完成=100*sum(d<=2 for d in done)/N,未完成=100*sum(d==99 for d in done)/N,
                完成前伤害=m(pre),完成后伤害=m(post),完成后三伐次数=m(uses),慎图率=100*m(stt) if stt else float('nan'),
                三同花=m(tri),对子以上=m(pairs),回合外反伤=m(refl),首回合手牌=m(fh),慎图次数=m(shentu),存活=100*alive/N)
```

```python
# ============================================================
# run_1v1.py —— “成”是主要进攻者的情形（近似1v1）
# 用途：第六部分削弱预案A（黑色改为可被【闪】响应的杀）在“成”为主要进攻者时的影响：
```

#### 13．sim.py　旧版、2.0、3.0的对局模型（第一代）

对应：桓温设计书2.0、3.0。状态：已被 model.py 取代，口径不同。

```python
# ============================================================
# sim.py —— 旧版、2.0、3.0 的对局模型（第一代模型，已被 model.py 取代）
# 用途：比较旧版（修订稿）与2.0、3.0；完成〖遂宁〗后每阶段发动1至3次〖三伐〗的表现。
#       对应桓温设计书2.0、3.0中“推演”的数字。本文4.2中的版本比较改用 model.py 重算，
#       两代模型口径不同，数字不能直接比较。
# 运行：python3 sim.py 20000      参数为每组局数。
# 输出：完成均值（第几轮完成〖遂宁〗）、2轮内完成%、8轮未完成%、完成前/后每回合伤害、
#       完成后慎图%、每回合总伤害、8轮存活%、终局体力上限。
# 主要简化：〖三伐〗不控顶（牌堆顶不留牌）；交换只放一张最没用的手牌入牌堆底；
#       他人每轮以40%概率伤“成”1点；目标的【闪】按泊松分布（乐观0.6张，保守1.25张）。
# 版本代号：old=修订稿（对子+1杀，三同花下一张杀不可响应，黑色视为杀“成”）；
#       2.0=对子无次数限制、三同花全部不可响应、获得的牌不计入手牌上限；
#       3.0=2.0去掉“不计入手牌上限”。
# ============================================================
import random, sys
from statistics import mean
# 牌型：S杀 D闪 T桃 J酒 U决斗 A南蛮/万箭 F火攻 K其他锦囊 E装备/其他基本
TYPES=['S']*44+['D']*24+['T']*12+['J']*5+['U']*3+['A']*4+['F']*3+['K']*40+['E']*25
def card(r): return (r.choice(TYPES), r.randrange(4))
TRICK=set('UAFK')
class Dead(Exception): pass
def poisson(r,mu):
    k=0; L=2.718281828**-mu; p=1.0
    while True:
        p*=r.random()
        if p<L: return k
        k+=1
def run(ver,cons,k_after,N=20000,R=8,seed=11):
    r=random.Random(seed)
    shan_mu=1.25 if cons else 0.6; bagua=0.3 if cons else 0.0; reach_after=0.6 if cons else 1.0
    res=dict(done=[],dmg=[],tdmg=[],shentu=[],alive=0,mx=[],pre_dmg=[],post_dmg=[],post_st=[])
    for _ in range(N):
        hp=mx=3; hand=[card(r) for _ in range(4)]; free=0
        cheng=4; prog=0; done=None; dmg=0; st=0; turns=0; pre=[]; post=[]; postst=[]
        try:
            for rd in range(1,R+1):
                # ---- 自己回合 ----
                turns+=1
                hand+= [card(r),card(r)]
                tgt_shan=poisson(r,shan_mu)
                def hit_sha(unresp):
                    nonlocal tgt_shan
                    if unresp: return True
                    if bagua and r.random()<bagua*0.5: return False
                    if tgt_shan>0: tgt_shan-=1; return False
                    return True
                reachable = done is None or r.random()<reach_after
                if done is None: uses=1
                else: uses=k_after if reachable else 0
                ph_dmg=0; sha_lim=1; unlimited=False; unresp_all=False; next_unresp=0
                for _u in range(uses):
                    if not hand: break
                    # 交换：放一张最没用的到牌堆底
                    hand.sort(key=lambda c:'EKTDJUAFS'.index(c[0])); hand.pop(0); hand.append(card(r))
                    top=[card(r) for _ in range(3)]
                    cnt=max([sum(1 for c in top if c[1]==s) for s in range(4)])
                    X=cnt if cnt>=2 else 1
                    got=top[:X]; hand+=got
                    if ver=='2.0': free+=X
                    if cnt>=2:
                        if ver=='old': sha_lim+=1
                        else: unlimited=True
                    if cnt==3:
                        mx+=1
                        if ver=='old': next_unresp+=1
                        else: unresp_all=True
                def deal(n):
                    nonlocal cheng,prog,ph_dmg,dmg,done,hp,mx
                    ph_dmg+=n; dmg+=n
                    if done is None:
                        prog+=n; cheng-=n
                        if prog>=3 or cheng<=0:
                            done=rd; mx+=1; hp=mx
                if reachable:
                    # 酒
                    buff=0
                    # 火攻（伏火：锦囊+基本）
                    ks=[c for c in hand if c[0] in 'K']; bs=[c for c in hand if c[0] in 'SJE']
                    if ks and bs:
                        hand.remove(ks[0]); hand.remove(bs[0])
                        if r.random()<(0.75 if len(hand)>=3 else 0.5): deal(1)
                    # 决斗
                    for c in [c for c in hand if c[0]=='U']:
                        e=poisson(r,0.5 if not cons else 1.0)
                        hand.remove(c)
                        if unresp_all: deal(1); continue
                        mys=sum(1 for x in hand if x[0]=='S')
                        if mys>=e:
                            for _ in range(e): hand.remove(next(x for x in hand if x[0]=='S'))
                            deal(1)
                        else:
                            for _ in range(mys): hand.remove(next(x for x in hand if x[0]=='S'))
                            hp-=1
                    for c in [c for c in hand if c[0]=='A']:
                        hand.remove(c)
                        if unresp_all or r.random()<0.5: deal(1)
                    used=0
                    while any(c[0]=='S' for c in hand) and (unlimited or used<sha_lim):
                        if any(c[0]=='J' for c in hand) and buff==0:
                            hand.remove(next(c for c in hand if c[0]=='J')); buff=1
                        hand.remove(next(c for c in hand if c[0]=='S')); used+=1
                        un = unresp_all or next_unresp>0
                        if next_unresp>0: next_unresp-=1
                        if hit_sha(un): deal(1+buff)
                        buff=0
                while any(c[0]=='T' for c in hand) and hp<mx:
                    hand.remove(next(c for c in hand if c[0]=='T')); hp+=1
                # 慎图
                if uses>0 and ph_dmg<uses:
                    mx-=1; st+=1
                    if mx<=0: raise Dead()
                    hp=min(hp,mx)
                    if done is not None: postst.append(1)
                elif done is not None and uses>0: postst.append(0)
                (pre if done is None or done==rd and uses==1 else post).append(ph_dmg)
                # 弃牌
                lim=hp+(free if ver=='2.0' else 0)
                if len(hand)>lim:
                    hand.sort(key=lambda c:'TDKSJUAFE'.index(c[0])); hand=hand[:lim]
                    if ver=='2.0': free=min(free,len(hand))
                # ---- 他人回合 ----
                if done is None:
                    other=r.random()<0.4
                    if other: cheng-=1
                    if cheng<=0 and done is None: done=rd; mx+=1; hp=mx
                k=poisson(r,0.6)
                for _ in range(k):
                    d=[c for c in hand if c[0]=='D'] or [c for c in hand if c[0] in TRICK]
                    if d:
                        hand.remove(d[0])
                        if free: free-=1
                        if done is None:
                            col=r.random()<0.5
                            if col: hand.append(card(r))
                            else:
                                atk_is_cheng = r.random()<1/3
                                if ver=='old':
                                    un=len([1 for _ in range(4)])<=len(hand)  # 成手牌约4
                                    if un or tgt_shan==0 or r.random()<0.4:
                                        prog+=1; cheng-=1; dmg+=1
                                else:
                                    dmg+=1
                                    if atk_is_cheng: prog+=1; cheng-=1
                                if done is None and (prog>=3 or cheng<=0):
                                    done=rd; mx+=1; hp=mx
                    else:
                        hp-=1
                        while hp<=0:
                            if any(c[0]=='T' for c in hand): hand.remove(next(c for c in hand if c[0]=='T')); hp+=1
                            else: raise Dead()
            res['alive']+=1
        except Dead: pass
        res['done'].append(done if done else 99); res['dmg'].append(dmg/turns); res['shentu'].append(st); res['mx'].append(mx)
        res['pre_dmg']+=pre; res['post_dmg']+=post; res['post_st']+=postst
    d=sorted(res['done'])
    fin=[x for x in d if x<99]
    return {'完成均值':mean(fin) if fin else 0,'2轮内完成%':100*sum(x<=2 for x in d)/N,'8轮未完成%':100*sum(x==99 for x in d)/N,
            '完成前每回合伤害':mean(res['pre_dmg']) if res['pre_dmg'] else 0,'完成后每回合伤害':mean(res['post_dmg']) if res['post_dmg'] else 0,
            '完成后慎图%':100*mean(res['post_st']) if res['post_st'] else 0,'每回合总伤害':mean(res['dmg']),'8轮存活%':100*res['alive']/N,'终上限':mean(res['mx'])}
if __name__=='__main__':
    N=int(sys.argv[1])
    for cons in (False,True):
        for ver in ('old','2.0','3.0'):

                print('保守' if cons else '乐观',ver,'完成后发动',k,' '.join(f'{a}={b:.2f}' for a,b in o.items()))
```
