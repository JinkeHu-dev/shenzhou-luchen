# Manual verification / 人工验证记录

Target: NoName v1.11.6, TEST mode, Huan Wen 4.2.

目标环境：无名杀v1.11.6，TEST模式，桓温4.2。

## Verified cases / 已验证项目

- A Dodge converted through Fuhuo enters the normal response event and can trigger Suining.
- A black Suining judgment damages the user of the responded-to card; damage to an unmarked character does not advance Cheng progress.
- Three actual damage points dealt to the Cheng-marked target complete Suining once, heal Huan Wen to the new maximum, remove Cheng and Suining, and upgrade Sanfa to three uses.
- Sanfa exchanges the physical top card with the selected hand card. The exchanged-in card participates in the following three-card reveal.
- The allocation dialog rejects more than two top cards and preserves the selected top and bottom order.
- When more than X cards are placed on the bottom, the undrawn remainder stays in the physical draw pile and can be recovered by a later Sanfa.
- Each X ≥ 2 result adds one Slash use for the current Play Phase; multiple results stack.
- X = 3 grants one maximum health and makes the next card, including a trick, unrespondable. The effect is consumed exactly once.
- Shentu does not trigger in a Play Phase where Sanfa was not used. It compares actual phase damage against the number of Sanfa activations.

- 伏火转化的【闪】沿正常响应事件触发遂宁。
- 遂宁黑色判定伤害所响应牌的使用者；伤害非“成”角色不推进累计。
- 对“成”实际造成累计3点伤害时，遂宁只完成一次：增加上限、回满、移除标记与技能，并把三伐升级为三次。
- 三伐交换真实牌堆顶；换入的手牌参与随后三张亮牌。
- 分配界面禁止牌堆顶超过两张，并保持玩家指定的顶、底顺序。
- 置入牌堆底超过X张时，未摸出的牌保留在真实牌堆底，可在后续三伐中取回。
- 每次X不小于2都使本阶段【杀】次数+1，多次结果可以累加。
- X为3时增加1点体力上限，下一张牌（包括锦囊）不可被响应，且效果只消耗一次。
- 未发动三伐的出牌阶段不会触发慎图；慎图比较的是本阶段实际伤害值与三伐实际发动次数。
